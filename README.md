# Controlling-four-DC-motors-
## Project overview 
Arduino-based simulation of a four-wheel robotic vehicle using dual L293D motor drivers. The project demonstrates sequential motor control including forward motion, reverse motion, and alternating right/left turns in Tinkercad.

## Components 
- Arduino Uno
- Two motor drivers (L293D)
- Four DC motors
- Breadboard
- Jumper Wiers

 ## Motor Sequence
  1. Move forward for 30 seconds.
  2. Move backward for 60 seconds.
  3. Alternate between right and left turns for 60 seconds.
  
  ## Software 
  - Tinkercad
  - Arduino IDE (C++)
